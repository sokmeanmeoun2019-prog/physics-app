Outstanding Worksheet Library (Grade 9 & Grade 12 Only)
============================================================

This folder stores Outstanding Worksheet PDFs independently of the existing Ebook, EN-Worksheet, KH-Worksheet, KH-Ebook, and Summary Slides libraries.

Structure:
- grade9/   (*.pdf, catalog.json)
- grade12/  (*.pdf, catalog.json)
- catalog.js

How to add worksheets:
1. Run Preview_Website_Locally.bat (or node server.js) and upload PDFs directly in the Outstanding Worksheet tab as Administrator, OR
2. Copy PDF files into grade9/ or grade12/ and double-click Sync-Outstanding-Worksheets.bat before running Upload_To_GitHub.bat.
