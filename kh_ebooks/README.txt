KH-Ebook Library (Grades 7-12)
================================

This folder stores Khmer-language Physics PDF textbooks independently of the English Ebook library.

Structure:
- grade7/   (PDF files + catalog.json)
- grade8/   (PDF files + catalog.json)
- grade9/   (PDF files + catalog.json)
- grade10/  (PDF files + catalog.json)
- grade11/  (PDF files + catalog.json)
- grade12/  (PDF files + catalog.json)

How to add books:
1. Run `node server.js` and upload PDFs directly in the KH-Ebook tab as Administrator, OR
2. Copy PDF files into the corresponding `grade{N}/` folder and run `Sync-KH-Ebooks.bat` before running `Upload_To_GitHub.bat`.
