WIS Physics Learning Hub - Summary Slides Folders (Grade 9 & Grade 12 Only)
==========================================================================

Folders:
  summary_slides/grade9/kh/   -> Grade 9 KH-Physics summary slides (.pdf, .pptx, .ppt)
  summary_slides/grade9/en/   -> Grade 9 EN-Physics summary slides (.pdf, .pptx, .ppt)
  summary_slides/grade12/kh/  -> Grade 12 KH-Physics summary slides (.pdf, .pptx, .ppt)
  summary_slides/grade12/en/  -> Grade 12 EN-Physics summary slides (.pdf, .pptx, .ppt)

How to Add or Replace Files for GitHub Pages:
  1. Copy your .pdf / .pptx / .ppt files into the matching folder above.
  2. To replace an existing slide, keep the same filename and overwrite it, OR
     run "node server.js" locally once (it auto-updates catalog.json when adding/removing new filenames).
  3. Commit & push the "summary_slides/" folder to GitHub to go live directly.

Recommended Filenames (Optional):
  Grade 9:  g9-ch1-summary-slides.pdf, g9-ch2-summary-slides.pdf, ...
  Grade 12: g12-ch1-l1-summary-slides.pdf, g12-ch1-l2-summary-slides.pdf, ...
