WIS PHYSICS HUB - OFFICIAL AUDIOBOOK NARRATION FILES DIRECTORY
========================================================================

WHERE TO PUT YOUR FILES:
  Put all your audio files directly into this "audio\" folder:
  d:\Building App\Summarize formula_web\audio\
  (Note: You can also place them in "audiobooks\", both work seamlessly!)

SUPPORTED FILE FORMATS:
  .mp3  (Recommended)
  .m4a  (AAC audio from iPhone / Voice Memos)
  .wav  (High quality)
  .aac, .ogg

HOW IT WORKS IN THE WEB APP:
  When a student or teacher opens any chapter in the E-Book viewer,
  an interactive "Audio Parts" pill selector appears automatically.
  Students can click between Part 1, Part 2, Audio 3, etc. to listen
  to each narration file while reading the book pages!
